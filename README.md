# 中转站收录
整理公开可访问的 AI API 中转服务信息，方便开发者按模型覆盖、价格和服务透明度进行比较。
> 本项目是信息索引，不提供中转服务，也不代表对任何服务商的背书。服务能力、价格、可用性和条款可能随时变化；使用前请自行核实，并避免提交敏感数据。

模型定价页独立于模型能力排行榜：型号与报价从 BaseLLM LLM Metadata 同步，美元报价保持原值；额外收录火山引擎（Volcengine Ark）的非弃用按量计费模型，将其人民币输入、输出及缓存读取价格按固定汇率 **1 USD = 6.67 CNY** 除以 6.67 换算为美元（非官方美元报价，不使用实时汇率），不收录 Coding Plan 订阅。另外在 `server/volcengine-media-prices.ts` 维护直接核对火山引擎官方价格页的 Seedream 图片及 Seedance 视频在线推理报价（核对日期 2026-10-27），由价格 API 合并返回，不依赖 BaseLLM 是否收录多模态模型。Seedream 按张图片计费，Seedance 按百万视频 Tokens 计费；API 保留输入视频、分辨率、图片像素与图层拆分等分档条件，页面仅展示基础单价，不显示“计费条件与分档”折叠区，不将官方示例每秒价格误作统一单价。更新报价时应同时修改核对日期与测试。页面来源链接指向火山引擎官方模型价格页，顶部筛选及“厂商”列使用厂商 Logo（位于名称左侧），豆包 Seed、Seedream、Seedance 模型名称左侧使用豆包模型 Logo。豆包型号按官方价格页原文显示，如 `doubao-seed-2.0-lite`、`doubao-seedream-5-0-pro`、`doubao-seedance-2.0`，不自行添加中文品牌前缀或改写版本分隔符。模型按厂商和基础型号合并日期、预览与推理模式版本；不同服务商的报价分别展示。缓存读取价格取自 BaseLLM 的 `cost.cache_read`（美元 / 百万 Tokens），不使用缓存写入价格或普通输入价格补缺；数据库沿用 `cached_input_price` 列存储该值，API 使用 `cacheReadPrice` 字段返回。没有报价的型号保留并显示“—”，不使用排行榜价格补缺。定价页不展示 Arcee、Cohere、Inception、Mistral、Morph、Nova、Poolside、Sakana AI、Sarvam AI、StepFun (Global)、Thinking Machines 和 Upstage 的模型；此过滤仅作用于定价页。

定价表格的“模型能力”列按源数据展示多个标签：对话、深度思考、识图、语音、视频理解、图片生成、视频生成、长文本，不再混入“开源”或“通用”。同步时将 BaseLLM 的 `type`、`modalities` 和 `limit` 保存到 `capability_metadata`；长文本标准为上下文窗口 ≥ 200,000 Tokens，悬停标签显示实际 Tokens 数。识图与视频理解要求对应输入模态及文本输出，生成模型单独标注生成能力；未确认的能力不按名称推测。旧数据需运行 `npm run db:sync-prices` 补齐元数据；缺失元数据的历史文本模型仅回退显示对话及已有的深度思考标记，无法分类时显示“未说明”。

定价表格的“模型ID”列显示 API 的 `modelId`（所保留型号的原始模型 ID），保留日期后缀及版本分隔符，不添加厂商前缀或用显示名称替代；搜索支持模型 ID、名称与厂商，方便后续与中转站 `/models` 接口返回的 ID 对照。现有基础型号合并规则不变，未保留的版本 ID 不单独展示。模型公司列同时显示厂商 Logo 和名称；移除价格来源列，来源链接统一保留在页面底部说明区域。新增的发布时间列读取 BaseLLM `release_date`，持久化到数据库同名列，并通过 API `releaseDate` 返回。显示所保留默认型号的发布日期，不使用价格核对日期或同步时间代替；缺失时显示“—”。

## 账号与邮件配置

本地账号支持邮箱验证码注册、用户名或邮箱登录，以及邮箱验证码重置密码。验证码 10 分钟有效，同一验证码最多尝试 5 次，发送及认证接口包含基础频率限制。SMTP 凭据只从环境变量读取；复制 `.env.example` 为 `.env` 后配置 `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_FROM`，并为 `EMAIL_VERIFICATION_SECRET` 设置独立随机密钥。

登录、注册、发送验证码和重置密码均使用 Cloudflare Turnstile，并在服务端验证一次性 Token 及对应 action；前端验证结果本身不作为可信依据。请在 Cloudflare Turnstile 控制台添加生产域名和本地开发域名，然后配置 `TURNSTILE_SITE_KEY` 与 `TURNSTILE_SECRET_KEY`。HTTPS 生产环境还应设置 `COOKIE_SECURE=true`。

## 收录字段

- **服务商**：服务或品牌名称。
- **支持模型 / 厂商**：仅列公开页面明确支持的模型或模型厂商；模型列表变化较快，必要时链接至官方模型页。
- **价格说明**：标明计价单位、适用模型或分组；优惠、倍率和充值赠送应注明条件。
- **站点分组**：收录站通过服务商公开的 New API / One API 兼容计价接口自动探测全部分组、类型、倍率和可用模型数量，不由提交者填写。无法公开探测时会明确标记。
- **官网**：服务商公开的官方网站或文档地址。
- **补充说明**：填写其他有助于用户选择服务的信息，内容较多时请精简概括。

## 提交与更新

欢迎通过 Issue 提交新服务或修正信息。请提供服务商官网，以及需要新增或修改的具体内容。

建议按以下格式提交：

```text
服务商：
官网：
支持模型 / 厂商：
价格说明及计价单位：
补充说明：
```
### 填写要求

为保证列表简洁、易于浏览，请尽量使用简短、可核实的描述：
- 服务商名称不超过 20 个字。
- 支持模型只列主要模型厂商，三个厂商以上使用“等”概括。
- 价格说明只填写主要价格或计费方式；分组与倍率无需填写，由收录站自动探测。
- 官网只提交一个主要入口。
- 其他活动、套餐、模型清单和补充信息请填写在“补充说明”中，言简意赅。
提交内容不会原样复制到列表。维护者可能在不改变原意的情况下对内容进行精简、统一格式或拆分。
## 收录原则

- 仅整理公开信息，不收录盗号、账号共享、来源不明或明显违反服务商条款的服务。
- 不以付费排名；如未来出现赞助或合作内容，会单独标注。
- 优先保留可核验的官网、文档、价格说明和服务条款。
- 对失效链接或长期无法核实的信息进行标记，并在复核后更新或移除。
- 收录不等于安全、稳定、合规或持续可用的保证。

## 使用提醒

使用第三方中转服务前，请认真阅读其隐私政策、服务条款、退款规则和数据处理说明。API 请求、提示词、文件及密钥可能经过服务商或其上游系统；不要发送个人敏感信息、客户数据、机密代码或未公开资料。为 API 密钥设置最小权限和额度，并定期轮换。

请自行确认服务的使用方式符合所在地法律法规、模型提供方条款及组织内部要求。价格与服务状态可能随时变化，付款前应以服务商当时公布的信息为准。

## 站点分组报价与凭证

本地账号提交并审核通过的站点可在「站长授权与报价」中按分组提交专用 KEY 和人工报价。管理员审核通过后，报价才进入模型详情对比；公开探测分组不参与对比。账号关联只证明提交者身份，不证明域名或 KEY 的控制权，授权者须确保有权提交。历史提交因无法可靠确认本地账号绑定，暂不可使用该功能；OAuth 账号暂不支持分组授权。

在服务环境配置独立的 `SITE_CREDENTIAL_ENCRYPTION_KEY`（32 字节随机值的 64 位十六进制表示），妥善保管并与数据库分离；未配置时禁止保存 KEY，丢失或更换密钥会使已有密文无法使用，需要重新授权。撤销授权会删除该分组密文并停止公开相关报价。部署必须使用 HTTPS，反向代理需要使服务端识别的协议和 Host 与浏览器 Origin 一致。此阶段尚未接入定时检测、临时 KEY 测试或实际扣费验证，报价为站长声明并经人工审核，并不代表已验证账单。
